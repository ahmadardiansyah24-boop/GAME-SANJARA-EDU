# SANJARA EDU — Knowledge Battle

Game edukasi Benar/Salah dengan nuansa battle, camera support, responsive layout, scoring, timer, and background music integration.

## Struktur
- `index.html` — aplikasi utama SANJARA EDU V13
- `assets/audio/sanjara-battle-bgm.mp3` — musik battle (upload file MP3 ke folder ini)

## Menjalankan
Buka `index.html` melalui GitHub Pages atau hosting statis.

> Catatan musik: browser memulai audio setelah interaksi pengguna. Pada versi ini musik diarahkan ke `assets/audio/sanjara-battle-bgm.mp3` agar source code dan aset terpisah.
